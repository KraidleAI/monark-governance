## What it records

The recorder stands the harness up IN-PROCESS on a real `127.0.0.1` ephemeral listener (`startServer`)
and drives:

1. **MCP** (`mcp.` Host) — a real `initialize`, `tools/list`, and three `tools/call` JSON-RPC requests
   over the streamable-HTTP transport (the response is framed as `text/event-stream`), NOT `tool.run()`
   calls.
2. **HTTP/JSON mirror** (`api.` Host) — one `calibrate` call, to show both surfaces return the same
   `structuredContent`.

The steps: `gate` on the committed USDe key of `stable-run-velocity-24h` (step 3, `committed-gate`); `gate` on a
predictor of the same class whose calibration is not committed (step 4, `uncalibrated-gate`); `calibrate` on 20
caller-carried scores (step 5); its mirror (step 6). `judge` is listed by `tools/list` but not called here: it runs
the Genkan kernel, which the kernel tests drive (`npm run test:genkan`).

## The honest decisions the demo produces

- **committed USDe key = `commit` / `covered`.** The `stable-run-velocity-24h` calibration of the USDe key is measured
  (calm-window redemption flow, non-stationary across half-years; no coverage is measured), `scores_sha256`
  `e44a68b6…`; alpha and nMin are imposed by the server.
- **uncalibrated predictor = `abstain` / `under_calib`.** No calibration is committed for it, so the gate abstains.
  That abstention is the honest, expected result.
- **calibrate = q̂ 0.36**, the 19th of the 20 sorted scores (rank ceil((n+1)(1-alpha)) at alpha 0.1). It commits no
  calibration and serves no decision; its label states the exchangeability hypothesis.
- **B_t is caller-carried.** `remainingBudget` enters as a gate parameter and the SAME value leaves as
  `remaining_budget`. The stateless server does NOT deplete it (`packages/hikae/src/l3-gate.ts`).

These statements live in the trace's `honesty` block and are re-asserted by `test/h5-e2e-probe.test.ts`.

## Determinism and integrity

- The tools read no clock (`produced_at` is caller-carried); the ephemeral port is intentionally NOT recorded.
  Re-running the recorder reproduces the file byte-for-byte (two consecutive runs printed the same digest on
  2026-11-04).
- **sha256 (LF)** of `h5-e2e-trace.json`: `ed51ceb1c29cc4fb6e8bef069493709a6effc7f5933edafe35152708d91e43d2`
  (14848 bytes). Prior pin `7da12dd3…` (22291 bytes, the trace with `cascade` and `attest`). `.gitattributes`
  normalizes to `eol=lf`, so this digest survives commit; the probe LF-normalizes before hashing, so it also survives
  a CRLF checkout. This value is pinned as `TRACE_SHA256_PINNED` in `test/h5-e2e-probe.test.ts`.
- **Re-pinning**: the digest changes whenever the `tools/list` wire bytes, the `content` prose, the
  `initialize` step's `serverInfo.version` or a served decision changes. Regenerate, never hand-edit:
  `node scripts/record-h5-e2e-trace.mjs`.

## How the probe is mock-discriminating

`probe_harness_records_real_decision` re-drives the SAME chain live and `deepEqual`s it to this committed
file (faithfulness), then — because a replayed trace could copy the demo values — drives TEST-CHOSEN
PERTURBED inputs that are NOT in this trace over the same wire seam (`mcpToolsCall`) and requires the LIVE
response to equal an INDEPENDENT recompute:

- `calibrate` on the 31 scores k/31 at alpha 0.05, 0.2 and 0.01 ⇒ q̂ 30/31, 25/31 and `under_calib` (a hand-rolled
  split quantile; the demo holds only q̂ 0.36), so a frozen/mock trace reds;
- `gate` with a perturbed `B_t=0.4242` ⇒ `remaining_budget=0.4242` (echo), so a frozen constant reds;
- the committed `verdict.scores_sha256` == the USDe committed scores digest.
