## What it records

The recorder stands the harness up IN-PROCESS on a real `127.0.0.1` ephemeral listener (`startServer`)
and drives:

1. **MCP** (`mcp.` Host) — a real `initialize`, `tools/list`, and four `tools/call` JSON-RPC requests
   over the streamable-HTTP transport (the response is framed as `text/event-stream`), NOT `tool.run()`
   calls. This CLOSES the deferred residual "seam SDK `tools/call` (gate/cascade/attest not exercised via
   `createHarnessHandler`)" from an earlier lot.
2. **HTTP/JSON mirror** (`api.` Host) — one `cascade` call, to show both surfaces return the same frozen
   `structuredContent`.

The chain (per C-6): `cascade`(UKEMI) → `Prediction`, then `gate` → `GateDecision`; and `attest` →
`AttestedPrice` (the Shōgen projection).

## The honest decision the demo produces

- **cascade → gate = `abstain` / `under_calib`.** No cascade calibration is committed (ADR-M005 D5), so
  the gate abstains. That abstention is the honest, expected result — the demonstration's whole point.
- **btc-dir-15m = `commit` / `covered`, over a SYNTHETIC calibration.** The btc-dir calibration is a
  HIKAE S2a plumbing fixture (`calib_digest` `fcebed27…`), declared synthetic, not a measured predictor.
  This decision is demonstrative, not a trading signal.
- **attest = demonstrative, not probative.** A projection of ONE committed, previously Shōgen-verified
  witness (Binance BTCUSDT, self-notarised); the verifier is not executed at call time.
- **B_t is caller-carried.** `remainingBudget` enters as a gate parameter and the SAME value leaves as
  `remaining_budget`. The stateless server does NOT deplete it (depletion would be monetisation, outside
  ADR-M005 scope, D6; `packages/hikae/src/l3-gate.ts:136`).

These statements live in the trace's `honesty` block and are re-asserted by
`test/h5-e2e-probe.test.ts`.

## How the probe is mock-discriminating

`probe_harness_records_real_decision` re-drives the SAME chain live and `deepEqual`s it to this committed
file (faithfulness), then — because a replayed trace could copy the demo values — drives TEST-CHOSEN
PERTURBED inputs that are NOT in this trace over the same wire seam (`mcpToolsCall`) and requires the LIVE
response to equal an INDEPENDENT recompute:

- `cascade` at `shock=0.6` ⇒ `yhat=150` (a hand-rolled Eisenberg-Noe clearing; the demo holds only
  `shock=0` ⇒ `yhat=100`), so a frozen/mock trace reds;
- `gate` with a perturbed `B_t=0.4242` ⇒ `remaining_budget=0.4242` (echo), so a frozen constant reds;
- `attest.sens_emis_digest` == the digest read straight from `s3-binance.constat.json`
  (`empreinte_sent_revele_sha256`), so a mock digest reds;
- btc-dir `verdict.calib_digest` == the real synthetic calibration digest.
