## 3. Le module (`history-collect.ts`)

- **CLI** : `node apps/dojo/src/history-collect.ts --phase A|B --state <dir> --mint-file <out/mint.txt> --cut <S_CUT> --max-calls <n> --max-credits <n> --max-ru <n> --course-end <AAAA-MM-JJTHH:MM:SSZ>` ; argv fermée (huit drapeaux, chacun une fois, valeur bien formée), sinon `usage` (code 64). Environnement : `HELIUS_CYCLE_ID`, `HELIUS_CYCLE_FLOOR`, `CHAINSTACK_CYCLE_ID`, `CHAINSTACK_CYCLE_FLOOR` ; clés et URL lues par le garde seul (`deps.env` transmis tel quel).
- **Refus avant tout verrou** (`DOJO_HISTORY_COLLECT_REFUSALS`) : `usage`, `outside_repo` (`--state` dans le dépôt), `mint_mismatch` (fichier du mint ≠ sha256 épinglé `9b4e275a…decb`, TU-3), `cycle_missing` (cycle absent ou plancher non strictement positif), `budget_guard` (garde ×10 : plancher helius + 10 × `--max-credits` > 8 000 000, ou plancher chainstack + `--max-ru` > 16 000 000), `state_missing` (`<state>/ledger`), `disk_space`, `phase_order` (phase B sans phase A close), `inputs_mismatch` (reprise avec d'autres entrées fixes), `lock_held` (verrou d'opérateur tenu, TY-12 : aucun appel).
- **Phase A** : pour a puis b, pages `getSignaturesForAddress` `[MINT, {limit: 1000, before?, commitment: "finalized"}]` jusqu'à la page courte ; l'entrée la plus ancienne de l'index entier doit être SIG0 (signature, emplacement, `blockTime`), sinon `creation_mismatch`.
- **Phase B** : fusion (`mergeIndexes`) ; pages gTFA chez a `[MINT, {transactionDetails: "full", sortOrder: "asc", limit: 100, encoding: "jsonParsed", maxSupportedTransactionVersion: 1, commitment: "finalized", paginationToken?}]` jusqu'à une page vide, un jeton absent ou vide, ou un dernier corps d'emplacement > S_CUT ; `getTransaction` chez b des signatures de R de chaque page (une signature des pages absente des deux index est contestée, X + 1, et lue chez b ; une signature de F n'est jamais demandée) ; compléments chez a des signatures de R absentes des pages, puis chez b ; admission par `admit` ; compteurs (vii) ; `composeChecks`.
- **Arrêts** (statut `partial`, motif, aucun `publish/`, aucun appel de plus) : refus du garde (`run_calls`, `run_credits`, `method_cap_unlisted`, `method_cap`, `cycle_cap`), contrôles de `history-read.ts`, `course_timeout`, `transport_fault`, `evidence_corrupt`. `unlock` servi en `finally` pour chaque opérateur ouvert ; le sha256 de chaque ligne `unlocked` (dernière ligne du grand livre, égale à la tête `<op>.head`) est consigné dans `run.json`.
- **Évidence** (`<state>/evidence/`) : `journal.jsonl` chaîné (`seq`, `prev_sha256` = sha256 de la ligne précédente avec son LF, `phase`, `op`, `unit`, `method`, `params_sha256`, `raw`, `raw_sha256`, `size`, `outcome` ∈ {ok, null, fault}), écrit par ouverture, écriture, `fsync`, fermeture ; `raw/<phase>/<op>/<sha256>.json.gz` en création exclusive ; `runs/<n>-<instant>/run.json`, `checks.json`, `SHA256SUMS` ; `status.json` (fichier temporaire, `fsync`, renommage). Première ligne du journal : `mint`, sha256 du fichier du mint, `cut`, sha256 des sources.
- **Reprise** : à l'ouverture, chaîne et réponses brutes vérifiées (`evidence_corrupt`), entrées fixes comparées (`inputs_mismatch`) ; chaque unité (phase, opérateur, méthode, curseur ou signature) close est servie depuis l'évidence, seules les autres sont appelées ; une faute journalisée n'est pas close.
- **Composition** (DOJO-HISTORY-CHECKS-COMPOSITION-1) : `composeChecks` = `checkSupply` + `checkInstructions` sur chaque admise, `checkCreation`, QC-2, `checkBounds(DOJO_HISTORY_BOUNDS)` ; appelée par la phase B (chemin servi) et par `closeHistory` avant `historyBundle` au statut `complete` (consommateur : PR-2b-4).
