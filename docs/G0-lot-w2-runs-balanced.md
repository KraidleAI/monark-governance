- **Contract of `balancedExceedance(values)`**: `values` a sequence of numbers in time order. Any NaN: `RangeError`. Over the distinct values t, ones(t) = the count of values > t; a t with ones(t) = 0 is skipped; the chosen t minimizes abs(2 ones(t) - n), ties toward the larger ones(t). No candidate (fewer than two distinct values, or no value): `{ empty: true }`. Else `{ empty: false, threshold: t, bits }` with bits = 1{v > t} in input order. t is a value of the sequence and depends on the multiset only; the choice uses counts and comparisons only (a comparison sort, integer counts), never a float arithmetic step. Infinities are ordinary values. The magnitude of `label_magnitude` and the admissibility of `aux_seq` belong to the guard (L2-3), not to the engine.
- **Out of scope**: `runsCount`, `runsLowerTailLeq` and their tests R-1 (unchanged), the guard of L2-3 (reading `empty` on checks 1 and 2, `aux_seq`, `order`), any served text, `schemas/**`, `packages/contracts/**`, any other test.

## 5. Declared deviations from the worksite G0 v3.1

- D-1: USDe. The worksite G0 R-4 and M-23 (after [AC2] R-1: "nothing changes on the served rows, whose median is already balanced") state 306 ones, the balanced threshold equal to the v3 median. Under the tie rule of ADR D6 as written (ties toward more ones) this is off by one: n = 613 is odd, 306 and 307 ones are equally close to n/2 (abs(2 x 306 - 613) = abs(2 x 307 - 613) = 1), and the 306th smallest value 1.242960625e-6 (distinct from the median 1.2461032083333333e-6) yields 307. The test pins the rule (307 ones, threshold 1.242960625e-6) and also pins the counting median and its 306 ones, so the difference is on record. liq s0 matches the worksite G0 (23 ones, threshold 0). To be recorded by RECHERCHES in M-23.
- D-2: R-4 killer mechanism. The worksite G0 names the intent "the skip of a value leaving no ones removed (case 3 then returns the cap)". With the skip removed, the cap still loses (abs(0 - 299) = 299 against 1), so case 3 does not see it; the skip only matters on a constant sequence, where the mutant returns a threshold instead of `empty`. The killer is the same mutant; it is killed by case 1 of the same test.
- D-3: the removal of `medianExceedance` is asserted in the test (`"medianExceedance" in` the module and the package entry is false); this is what makes the retargeted `runs_refuses_bad_inputs` red at the base.
- D-4: categories. The worksite G0 lists R-3b and R-4 as new-module; on the stacked base `runs.ts` exists, so they are F2P (red by assertion), as is the retargeted R-2 and `runs_refuses_bad_inputs`.
- D-5: R-25 above the worksite G0 estimate (235 insertions against about 140), still under the bound (section 3).
- D-6: the two served arrays are re-typed on long lines (25 values per line for USDe, 43 for liq s0) to keep R-25 low; their identity is checked by digest, not by layout.
