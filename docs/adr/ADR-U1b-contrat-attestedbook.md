- **Statut** : **proposé (G0)** — lot **U-1b** du programme ADR-M020, voie **(b)** de ADR-U1 D10. **Décision investisseur 16 (2026-09-19)** : « nouveau contrat gelé MONARK `AttestedBook`, lignée `AttestedFlow` (Narabi), auto-déclaré (ce que le recorder a lu, avec quorum de fournisseurs), hors Shōgen ». **Checkpoint-1 orchestrateur `claude-fable-5-1` sur `1bdea9c` : APPROUVÉ-AVEC-CORRECTIONS (C-1..C-12 pliées ici) ; point C (attestor objet dédié) tranché techniquement ; points A et B en signature investisseur.** Touche `schemas/` ⇒ checkpoint-1 avec signature investisseur. - **Propriétaire de la décision** : investisseur (programme Ukemi, ADR-M020) ; rédaction : worker `claude-opus-4-8[1m]` ; verdict/commit : orchestrateur `claude-fable-5-1` (R-20).

## Contexte (mesuré)
1. **ADR-U1 D10 voie (b) tranchée** : le book RPC ne peut **pas** produire un verdict Shōgen — `verifier_temoignage(temoignage, registre, constat: Option<&Constat>)` retourne `ConstatAbsent` si `constat = None` (`F:\Shogen\crates\shogen-core\src\verification.rs:288-291`, [lu]) ; (f) exige `attestor.key == constat.cle_du_controle` (l.349-356), (h) `hote_de_subject(subject) == constat.origine_authentifiee` (l.377-384). Une lecture **quorum-RPC keyless** n'a ni compagnon TLSN (`Constat`), ni origine authentifiée, ni clé de contrôle unique ⇒ jamais `Ok(Verdict)`.
2. **Lignée = la DISCIPLINE, pas une copie de champs.** `AttestedFlow` ([lu]) fixe le patron : `additionalProperties:false`, digests-**pas**-valeurs, `residual[]` **enum FERMÉ**, procédure recalculable, label K-1 **hors** contrat (`adapter-narabi.ts:64-66`), aucun score. `AttestedPrice`/`AttestedFlow` diffèrent déjà en champs ; `AttestedBook` a **ses** champs (D2). **Divergence assumée** : les aînés projettent un témoignage **contrôlé** ; `AttestedBook` est **auto-déclaré, aucun vérifieur** (D3).
3. **Doctrine des contrats gelés** : ADR-M001 Décision 9 (« un gelé n'évolue que par ADR », `schema_version`) ; garde CI `contracts_frozen` = ADR-M002 D2/D13 (test racine CA-0, hash LF vs manifeste) ; **précédent 5ᵉ = ADR-M008 D9 / E-M008-2** (AttestedFlow). `AttestedBook` = **6ᵉ** (D1).

**D2bis — `subject` : approximation nommée, non-port de C1-C10.** Regex `^https://[a-z0-9-]+(\.[a-z0-9-]+)+(/[a-z0-9._~-]+)+$`. **Couvre** C1 (ASCII), C2 (`https://` minuscule), C3 (reg-name minuscule, ni IDN ni crochets), C4 (pas de `@`), C5 (a fortiori : aucun port), C7 (exclusion de `%`), C8 (pas de requête), C9 (pas de `#`) — [lu] `subject.rs`. **Non-port déclaré** (motif `cbor-canonique.ts:25-29`), re-gardé fail-closed par le recorder (gabarit fixe) : C3-littéral-IPv4, C6-segments `.`/`..`, **label d'hôte à tiret initial admis** (C-5). **D2ter — `residual` (enum FERMÉ, propre au contrat, PAS le registre Shōgen).** v1 = `["no_third_party_verifier","oracle_price_as_read","oracle_source_as_read","rpc_quorum_2_keyless","block_timestamp_not_submission","emode_recompute_skipped"]`. `no_third_party_verifier` **toujours émis** (`minItems:1` jamais vacuous, C-10) ; `emode_recompute_skipped` (= « HF on-chain autoritaire, recompute e-mode sauté », déplacé depuis `abstain.reason`, C-1). **D3 — Ce que le contrat n'affirme PAS (description gelée, anglais, sans jeton probatif — C-10).** Cœur verbatim : « **Self-declared reading under keyless RPC quorum; no third-party verification; no price is carried.** » Complète : « Projection of a self-declared liquidation-book reading at an archive block — the SIXTH frozen contract of the fleet (Ukemi), lineage AttestedFlow. It carries the DIGESTS of the canonical book (book, holders) with the block, provider and quorum context that make them recalculable against a keyless RPC quorum; the price numbers stay in the book pointed to by `subject` (not frozen), same discipline as AttestedPrice. `book_digest` is the SHA-256 of the canonical book when recorded, or of the canonical abstention record when the whole read abstained. No score, no truth field (fleet forbidden-keys apply). ADR-U1b. » **Oracle d'honnêteté** (C-8, D6) : scrub PROBATIVE de `attest.test.ts:109` (`/live|verified|probative|p_correct|confidence/i`) sur cette `description` après masquage des négations nommées (« no third-party verification », « No verifier runs ») ⇒ aucun jeton probatif ne survit ; rien ne police « verified » dans `schemas/` aujourd'hui.

**D4 — Book abstenu : témoin TOTAL (point A, signature investisseur).** ADR-U1 D3 : `no_quorum` ⇒ tout le book abstient, « jamais un book partiel ». `AttestedBook` est **toujours émis**, `abstain={value,reason}`, `reason` **fatal seul** enum `[null,"no_quorum","abi_mismatch","unfinalized_block"]`, couplage **`value ⇔ reason≠null`** re-gardé + testé (C-1). Sous abstention fatale : `book_digest` = SHA-256 de l'**enregistrement d'abstention canonique** `{cluster,block,reason,providers}` (recalculable, non-null) ; `holders_digest` = digest de l'ensemble **vide** ; `eligible={"0","0","0"}` ; `oracle_sources=[]` (`minItems:0`). **Le fichier pointé par `subject` EXISTE et contient cet enregistrement** (C-11) ; le double domaine de `book_digest` est déclaré dans la description (D3) + mutant (D6). **Quorum par méthode (C-4)** : `providers[].method ∈ {getLogs, eth_call}` ; `quorum.achieved = min` des concordances par méthode employée (`eth_getLogs` ⊂ {drpc,mevblocker,tenderly} ; `eth_call` ⊂ {drpc,mevblocker,blastapi,nodies}, ADR-U1 D3) ; `achieved < required` ⇒ `no_quorum`. **Alternative (point A)** : n'émettre que si `pair_status=recorded`, l'abstention fatale en timeline ADR-U1 D6 seule.
