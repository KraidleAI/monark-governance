## Contexte (mesuré)
1. **Faisabilité et coût établis (M-1, [lu] first-hand)** : reconstruire le book agrégat d'un cluster à un bloc **archive** B via `eth_call` keyless est faisable et bon marché — `getUserAccountData(user)@B` renvoie des octets **identiques sur 6 endpoints** (quorum-2), book de `0x552c4ad0…`@B décodé collatéral 18 038 $/dette 14 218 $/**HF 1,0530** (`MESURES-prealables-2026-09-19.md` §5, `out/m1-results.json` sha `986cffd9…`). `UiPoolDataProvider` courant **absent (0 octet de code) @B** (redéployé) ⇒ chemin auto-suffisant `getUserConfiguration@B` + `balanceOf`, **≈ 2,7 appels/compte** (`m1b-userconfig.mjs`, `out/m1b-userconfig.json`).
2. **Énumération sous-estimée par les logs de liquidation (M-1 caveat, pré-enregistré)** : l'ensemble *à-risque* qu'un recorder réel doit reconstruire n'est **pas** énumérable depuis `LiquidationCall` (ce sont les comptes déjà liquidés) ; il faut les **détenteurs d'aToken via logs `Transfer`**. N=213 comptes WETH liquidés (cluster 2025-10-10/11) est un **plancher**, pas le N réel.
3. **Prix et source par actif mesurables et datables (M-2b, [lu] on-chain)** : `getSourceOfAsset`+`description()` bissectés (`m2b4-source-bisect.mjs`, `out/…` sha `89719a0f…`) ; **AaveOracle = `0x54586bE62E3c3580375aE3723C145253060Ca0C2`** vérifiée via `PoolAddressesProvider(0x2f39d218…).getPriceOracle()` (le `…060Ca40C` d'un texte de mission antérieur = coquille, 0 octet). Source WETH = feed Chainlink **SVR backrun-only** (`0x5424384b…`, `AssetSourceUpdated` bloc 22803459) — `getAssetPrice` reste la vérité-terrain du HF quelle que soit la plomberie (§4.6).
4. **`liquidable-24h.ts` n'implémente PAS Perez Eq. 3** (vérifié cette session) : c'est un générateur de **paires synthétiques** seedées (`n=300`, `α=0.01`, résidu symétrique déclaré ; « no real 24h label », `packages/hikae/src/liquidable-24h.ts:9-13`). L'éligible statique d'U-1 est donc calculé **à neuf** : le prédicat liquidable de Perez (Eq. 3) = **HF < 1**, et le Pool **renvoie le HF on-chain** (`getUserAccountData.healthFactor/1e18`, [lu]) — c'est la source première, pas `liquidable-24h.ts`.
5. **`cbor-canonique.ts` est un décodeur/encodeur LIÉ au témoignage Shōgen 7-champs** (subject/attestor/residual/transport/utterance/observed_at/transport_proof), sans encodeur de valeur générale, et son sous-ensemble RFC 8949 déterministe **rejette** les entiers > u64 (`packages/monark/src/cbor-canonique.ts:9-16`) — or un book porte des uint256 (prix ×1e8, soldes ×1e18/×1e6). Il reste l'**enveloppe d'attestation** (voir D2), pas le sérialiseur du book.
6. **Asymétrie fournisseurs mesurée** : `eth_call` archive @B servi par **{drpc, mevblocker, blastapi, nodies}** (M-1 §5, ≥ 340–558/min soutenus ; tenderly rate-limite dès ~8 appels) ; `eth_getLogs` **large** archive servi par **{drpc, mevblocker, tenderly}** seulement — blastapi cap **10 blocs**, nodies **50 blocs** (census A §2). Le jeu de quorum **dépend de la méthode**.
7. **Vacuité intra-événement fixée (ADR-M020 D1(a), M-2/M-2b)** : Λ **indéterminé** (pas « = 0 »), canal endogène par l'oracle « coupé par construction » sur les clusters cibles (« cascade à prix endogène » de M020 D1(a)). U-1 est le **recorder sans gate** (objet (c)) ; gate/classe = U-4.

## Décision

**D1 — Objet du recorder `sentinel-2` (v1 : Aave v3 core Ethereum, collatéral WETH ; puis sUSDe/USDe, wstETH e-mode).** À un bloc archive **B** (fenêtre UTC ancrée bloc, motif Narabi `windows.ts`, B ≤ `finalized`), pour un **cluster déclaré**, le recorder produit un **book** :
- **Énumération de l'ensemble à-risque** : détenteurs d'aToken du collatéral via logs `Transfer` (topic0 `0xddf252ad…`, self-testé) depuis le **bloc de départ = log `ReserveInitialized(topic1=collatéral)` sur le PoolConfigurator** (topic0 `0x3a0ca721…`, census A §1 ; **jamais codé en dur**, résolu on-chain) jusqu'à B ; dédup des destinataires ; **prédicat à-risque = aToken `balanceOf` > 0 ∧ bit collatéral du cluster ON (`getUserConfiguration`) ∧ dette > 0**. Les exclus sont **comptés** (`excluded_zero_balance`, `excluded_collateral_off`, `excluded_no_debt`) et hors book — jamais un skip silencieux. Le passage `getUserConfiguration` **d'abord** borne le coût (D4).
- **Lecture par compte** : `getUserConfiguration`, `balanceOf` aToken/debtToken par réserve utilisée, HF **autoritaire** = `getUserAccountData.healthFactor` (brut 1e18), `getUserEMode`.
- **Prix + source par actif** : `getAssetPrice` (8 déc. brut), `getSourceOfAsset` + `description()` (motif `m2b4`).
- **Paramètres de réserve @B** (résolus via `getReservesList`+`getReserveData`, jamais adresse historique codée) : aTokenAddress, variableDebtTokenAddress, decimals, LT, LTV, liquidationBonus ; e-mode : `getUserEMode` porté ; catégorie e-mode (getters de signature v3.2+) lue **au lot du cluster e-mode**, abstention `abi_mismatch` fail-closed, jamais un repli sur le LT de base.
- **Bloc et hash de bloc** (quorum-2), chain id, pool, oracle, cluster id, paramètres d'énumération.
- **Éligible statique (Perez Eq. 3, [lu] via HF on-chain)** : par compte `eligible_static = (healthFactor < 1e18)` ; agrégé (compte + Σ collatéral/dette éligibles). **Invariant croisé** : recomputation `Σ(coll×prix×LT)/dette` ≈ HF on-chain ; pour tout compte à e-mode ≠ 0 en **v1 WETH**, marqué `emode_recompute_skipped` (le HF on-chain reste autoritaire).

**D2 — Digest canonique : JSON trié pour le book, Temoignage CBOR-canonique pour l'attestation.** Le **book** est sérialisé en **JSON canonique MONARK** (jeu de règles fermé, propre au projet, adossé à la discipline RFC 8949 déterministe déjà portée par `cbor-canonique.ts:9-16`) : clés triées par octets UTF-8, aucune clé dupliquée, tableaux en **ordre déclaré** (réserves et comptes triés par adresse), **tout entier en chaîne décimale** (uint256-sûr), **zéro flottant**, minifié (aucun blanc insignifiant), UTF-8. `book_digest = SHA-256(octets)`. **Périmètre du digest** = D1 sauf provenance ; **exclus** : endpoints, paires de quorum, latences, `node_version`, `sentinel_sha`, tout horodatage machine (leçon M-2 → M-2b : sha d'artefact reproductible seulement sans horodatage) — la provenance vit à côté.
*Justification du choix (contre CBOR pour le book)* : (a) `cbor-canonique.ts` est **lié** au témoignage 7-champs, sans encodeur de valeur générale (contexte 5) ; (b) major-0 cap u64 < uint256 du book ; (c) le book est un artefact d'inspection re-haché par un tiers (`jq -S -c`), JSON est lisible ; (d) le déterminisme est obtenu par la **même** discipline. `cbor-canonique` **reste employé** à la couche attestation.
**Attestation émise (pas d'appel à l'outil `attest`, K-8)** : le recorder **émet les octets** d'un **Temoignage** Shōgen (`encodeTemoignageCanonical`, ré-exporté sur le barrel `@monark/monark`) — `subject` = URL de l'état publié, `utterance.hash` = `book_digest` (32 o ; `bytes` omis, le book est publié à l'URL), `residual` = `["oracle_price_as_read","oracle_source_as_read"]` (c'est là que vit l'interdit : attesté **comme lu, pas comme vrai**), `attestor` = `[{identity:"monark-ukemi-recorder-v1", key:<convention déclarée, D-trancher>}]`, `transport` = `"rpc+eth_call+eth_getLogs"`, `observed_at` = `{clock:"eth-block-ts", instant: ts(B)}`, `transport_proof` = octets vides (déclaré). Le contrat gelé **`AttestedPrice` ne porte AUCUN nombre de prix** (`schemas/attested-price.schema.json` : « the price number is NOT carried here » ; champs subject/attestor/residual/transport/utterance/observed_at, [lu]) ⇒ le témoignage de book y entre **sans inventer de prix** (renforce D8). L'adaptateur existant `fromShogen(lot, verdictText, constat)` (`adapter-shogen.ts:206-238`) file `subject`/`attestor`/`utterance`/`observed_at` du Temoignage **tels quels** et prend `residual` d'un **verdict** Shōgen : U-4/U-6 ajoutent le verdict + une ligne `ATTESTATION_BINDING`, **sans ré-émettre le témoignage**. `attestor.key` = hex `^([0-9a-f]{2})+$` (schéma ; placeholder type Narabi `deadbeef`, D-trancher).

**D3 — Fournisseurs (quorum-2, par méthode, mesurés).** Refus si quorum absent : **abstention `no_quorum` consignée** (toute lecture — chunk, compte, réserve, source, prix, bloc — sans deux **fournisseurs distincts** concordants ⇒ tout le book `(cluster,B)` abstient en nommant la lecture fautive) ; **jamais un book partiel présenté comme complet**. Politesse ≤ **300 appels/min** (conservateur ; drpc mesuré ~558/min soutenu), retry par cooldown round-robin (motif `rpc.ts`, réutilisé sans le toucher).

| Étape | Méthode | Quorum-2 sur | Non retenus (mesuré) |
|---|---|---|---|
| Énumération détenteurs | `eth_getLogs` (large archive, split-on-cap) | **drpc, mevblocker, tenderly** | blastapi (10 blocs), nodies (50 blocs) — census A §2 |
| Book par compte/réserve/prix/source | `eth_call`@B | **drpc, mevblocker, blastapi, nodies** | tenderly (rate-limit ~8) — M-1 §5 |

Concordance = **SHA-256 du jeu trié** (logs par chunk : `(block,logIndex,topics,data)`, motif `A-chunks.jsonl` ; octets exacts pour `eth_call`). `providerOf` = domaine enregistrable (`rpc.ts:28`, réutilisé).

**D4 — Coût.** Départ ≈ bloc `16 291 127` (déploiement Aave v3, census A §1) → B ; pour B=23 545 087 ≈ **7,25 M blocs / 9 990 ≈ 727 chunks × quorum-2 ≈ ≥ 1 450 `eth_getLogs`** + splits sur cap-résultats (aWETH = token à fort volume ; census a fait 2 142 appels pour 6 M blocs de `LiquidationCall`, ici davantage). Puis global one-time ≈ **70 appels** (`getReservesList` + ~55–67 `getReserveData`) + par compte : `getUserConfiguration` (1) → filtre → `balanceOf`×réserves utilisées (~1,7) + `getUserAccountData` (1). **N_à-risque WETH = à mesurer au premier run** (borné haut par les destinataires distincts de `Transfer` aWETH à `balanceOf`>0) ; coût dominé par `N_holders × 1 + N_filtrés × ~2,7`. Temps @drpc/mevblocker/blastapi/nodies soutenus (quorum-2) : **minutes à basses dizaines de minutes**. **N et coût exacts consignés au G1 du premier run** (aucun N inventé).

**D5 — Oracle non-LLM (test) + mutants nommés (avant code).** Test d'intégration **`sentinel2_book_identical_to_pull`** (nom réservé **U-1** ; distinct de `sentinel2_windows_identical_to_pull`, réservé **U-6** par ADR-M020 D3 pour le découpage de fenêtres ; les deux calquent `sentinel_windows_identical_to_pull` de Narabi, `sentinel.test.ts:114`) : rejeu du book à B depuis une **fixture RPC stubbée pinnée par sha** = **liste des détenteurs énumérés** (adresses + `holders_digest` pinné) **+ réponses `eth_call`** par compte/réserve/source/prix (quelques Mo, committable ; les millions de `Transfer` **ne sont PAS committés**), produite par le premier pull réel à B=23 545 087 hors CI, sha au G1 (motif `fixtureRpc`, `sentinel.test.ts:84`) ⇒ le rejeu du `book_digest` **bit-identique** part de cette liste. L'**énumération** (`eth_getLogs`→détenteurs) est testée **à part** sur une **plage de blocs réduite épinglée** (mutant (3b) : un `Transfer` omis ⇒ `holders_digest` ≠ ⇒ compte manquant ⇒ digest ≠). Mutants (chacun rougit) : (1) **bloc décalé** B±1 ⇒ digest ≠ ; (2) **source d'oracle changée** (mock `getSourceOfAsset` renvoie une autre adresse) ⇒ digest ≠ ; (3) **compte omis** (drop d'un à-risque) ⇒ digest ≠ ; (4) **détenteur `balanceOf`=0 non exclu** ⇒ digest ≠ ; (5) **hash de chaîne cassé** (fait altéré dans une ligne) ⇒ `line_hash` recomputé ≠, ligne suivante détecte via `prev_line_hash` ⇒ **timeline refusée** (motif `sentinel_hash_chain`, `sentinel.test.ts:197`).

**D6 — Publication + timeline (motif Narabi).** `/ukemi/state.json` (dernier book_digest + méta cluster/B) + `/ukemi/timeline.jsonl` **append-only chaîné** : chaque ligne `(cluster, B, block_hash, from_block/to_block d'énumération, holders_digest, distinct_recipients, book_digest, temoignage_sha, prev_line_hash, line_hash, pair_status ∈ {recorded, no_quorum, abi_mismatch, unfinalized_block})`. `line_hash` sur les faits + digests **hors provenance** (calque `lineHashOf`). **`holders_digest`** (sha des adresses triées) + paramètres d'énumération dans la ligne ⇒ un tiers re-dérive l'ensemble depuis le départ ; cache incrémental des détenteurs autorisé pour la cadence quotidienne **à cette condition de vérifiabilité**.

**D7 — Regard `latest` interdit (look-ahead).** Le seul appel non-pinné est `finalized` (choix de B) ; **tout** `eth_call`/`eth_getLogs` porte **B explicite**. Test = grep du source `apps/sentinel/src/ukemi/**` pour le littéral `"latest"` (calque mutant M4, `sentinel_waits_for_finality`).

**D8 — Interdits (chacun testé ou grep `gate:vocab`).** Aucun **prix publié comme référence** (le book porte les prix oracle Aave, `residual=oracle_price_as_read`) ; aucun **« cascade »**, **score**, **« Λ = 0 »**, **« aurait alerté »** (ADR-M020 D2) ; aucun `latest` (D7) ; aucun chiffre [2nd] ; aucun sha d'artefact horodaté présenté comme reproductible.

**D9 — R-25 : taille > 400 l. estimée ⇒ scission.** Estimé **~700–900 l.** (rpc2 généralisé ~150 ; énumération+filtre ~120 ; lectures compte/réserve/prix/source ~200 ; assemblage+JSON canonique+digest ~140 ; éligible statique ~40 ; publication+timeline+temoignage ~130 ; tests+mutants ~250). **U-1a** = `apps/sentinel/src/ukemi/` recorder + JSON canonique + `book_digest` + éligible statique + `sentinel2_book_identical_to_pull` + mutants (1)(2)(3)(4). **U-1b** = publication `/ukemi/` + timeline chaînée (mutant (5)) + émission Temoignage + ré-export barrel. Chacun < 400 l., revoyable séparément (G2 fraîche par lot).

## Alternatives rejetées
- **`liquidable-24h.ts` pour l'éligible statique** : paires synthétiques, aucune donnée réelle (contexte 4) — non applicable.
- **CBOR-canonique pour le book** : encodeur lié au témoignage 7-champs, cap u64 < uint256, moins inspectable (D2) — réservé à l'attestation.
- **Énumérer depuis `LiquidationCall`** : sous-estime l'ensemble à-risque (M-1 caveat) — rejeté au profit des logs `Transfer` d'aToken.
- **Émettre un `AttestedFlow`** (contrat Narabi) : figé pour les flux de rachat (burns/mints/supply), pas un book ; et le gate consomme `AttestedPrice`, pas `AttestedFlow` — rejeté au profit du Temoignage (lignée `fromShogen`).
- **Publier une valeur de prix** (feed/référence) : viole l'interdit (attesté comme lu) — rejeté.
- **Modifier `rpc.ts`/`run.ts`/`timeline.ts`** : Narabi LIVE, ancre pinnée — rejeté ; module généralisé `ukemi/rpc2` important `providerOf`/`QuorumDisagreementError` sans les toucher.
- **Appeler l'outil `attest`** : produit la fixture Binance et importe le harness (K-8) — rejeté ; le recorder émet les octets Temoignage lui-même.
