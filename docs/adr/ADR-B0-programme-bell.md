## Décision

### D1 — Objet et doctrine
**MONARK Bell = (A) témoin public attesté des actions tokenisées** — faits **recalculables, sans gate, sans score** — **et (B) une classe conforme `tsv-offhours-gap-<horizon>` en espace d'écart, jamais en espace de prix** (contrat gelé du gate : « The price number is NOT carried here »), verdict commit/defer/**abstain** honnête sur l'intervalle du bras `interval` existant. **Interdits opposables** (mutants `gate:vocab` étendus à `apps/bell`, D5) : bande de prix ; « ±X % à 90 % » ; score/probabilité par événement ; « verified » nu ; « guarantee » (→ « bound ») ; « partner »/« partnership » (aucun TSV n'est partenaire) ; « live » dans le scope skills (M006) ; toute revendication de couverture quand l'écart de TV n'est pas nul. Bell **mesure**, ne **trade** pas (market making — produit 5 — **écarté**, décision investisseur 2 : en faire un « Covered Firm »/dealer changerait d'identité).

### D2 — Faits témoins v1 (lot T-1), sur xStocks (Solana : fills Raydium/Jupiter) et Ondo (Ethereum)
Publiés `bell.monarkgate.tech/state.json` + `…/timeline.jsonl` **JSONL append-only chaîné par hash de ligne** (`prev_line_hash`, motif Narabi ADR-M012 D4 ; une réécriture est **détectable, jamais certifiée** ; le seul garant est le recompute on-chain) **et signé Ed25519** (D8). Sources déclarées **par symbole × plateforme**.

| # | Fait recalculable | Définition (numérateur recalculé de première main) | Résidus nommés / honnêteté |
|---|---|---|---|
| i | **Écart de session** | `g_t = ln(P_token_VWAP_session / P_close_ref)` par session {régulier, pre, after, overnight-semaine, week-end, férié}. `P_token_VWAP` = VWAP des fills aux pools **déclarés** (jamais le ratio de réserves). `P_close_ref` = **dernier close consolidé (SIP) via Polygon** `v2/aggs/ticker/{T}/prev` puis `…/range/1/day/…`, **forward-fill déclaré** hors séance. **Convention de Bell, déclarée** : la littérature ne la fixe pas (L8) ; le LULD Plan reconnaît le « prior day's official closing price » comme référence *initiale* (l.748, « often ») et la Reference Price intraday comme « arithmetic mean … over the immediately preceding five-minute period » (Section V, l.219-221 [lu]) — Bell **n'endosse ni l'une ni l'autre comme vérité**, il déclare sa convention et la rejoue. | Close Polygon = **redistribution** du close SIP ⇒ **[2nd] déclaré** ; `ex_date_effect` : token rebasant garde ≈ le prix à l'ex-date pendant que le sous-jacent chute du dividende ⇒ **abstention** (nourrit T-2/T-3) ; bornes de session = **constante committée** à confirmer (CTS/UTP/flags Polygon, item T-1a) ; **calendrier férié + demi-séances 13:00 ET** = source à nommer (endpoint Polygon market-status, item T-1a). |
| ii | **Delta de halt** | Pour chaque halt du CSV (toutes places : Nasdaq/NYSE/NYSE American/NYSE Arca/Cboe BZX ; à la **seconde** ; `Reason` **normalisé en casse** : LULD / News / Corporate Action / Merger / Regulatory / ETF-component) → **premier fill on-chain après `Halt Time`** et **dernier avant `Resume Time`**. `Halt Time`/`Resume Time` en **ET sans fuseau** ⇒ conversion **ET→UTC avec DST**. Horodatage de **bloc ≠ soumission** ⇒ résidu. | **Témoin vide sur le sous-ensemble recensé (n = 0)** (Contexte 5 ; univers complet + source MWCB = items T-1a) : jamais un booléen « conforme » (« concurrently » sans tolérance, seuil côté lecteur). Résidus : `resume_unknown` (**4539** `NYSE Resume Time` vides, [lu]) ; `resume_date_gt_halt_date` ; `no_fill_in_window` (pause LULD de 5 min vs activité de pool) ; `block_ts_vs_submission`. |
| iii | **Volume on-chain par pool vs plafond** | Numérateur = volume des pools **déclarés** recalculé depuis les logs on-chain (Jupiter = agrégateur ⇒ compter les swaps **au niveau des pools**, dédupliqués par signature). Dénominateur = **ADV consolidé du mois précédent** (cond. F : « average daily **share** volume »). | Dénominateur Polygon = **[2nd] déclaré** ; jamais « le TSV est sous le plafond » (agrégation des affiliés non observable) ; **unité = actions** : token ≈ action **modulo le multiplicateur** ⇒ résidu `multiplier_unit`. |
| iv | **Supply on-chain vs PoR relayé** | Supply on-chain par chaîne (mints/burns), valeur PoR relayée + **staleness** (âge du `updatedAt`), écart, **taux des wrappers** (leçon Edel : taux wGOOGLx/GOOGLx ×78, oracle juste, ≈ 403 k$, R3 §4 [lu][P2]). | Phrase honnête : « S et Y diffèrent de X à t ; **Y n'est pas vérifiée contre le custodian** » ; votes = abstention déclarée. |

**Chemin servi T-1** : `state.json` + `timeline.jsonl` **lus par le panneau site `/bell/`** (motif Narabi, ADR-M012 D4). **Le triangle attest→gate n'existe PAS à T-1** : `attest` est input-less, ne projette que le témoin Binance committé, le harnais est **pur** (K-8, aucun réseau) ; Bell **ne peut** apparaître comme sujet `attest` sans lot-harness et BYO+`attested` est **refusé (400)** tant qu'aucune ligne de `attestation-binding.ts` n'existe pour la classe (ADR-M017 D2). Le sujet-URL Bell **arrive avec T-3** (ligne de liaison + re-pin h5), sous la même sérialisation harness que tout `gate.ts` (après U-4).

### D3 — T-2 (parité de droits) et T-3 (classe d'écart)
- **T-2 — parité de droits** (D2 (iv) approfondi) : ex-dates/montants depuis les corporate actions publiques ; **multiplicateur de rebase avant/après ex-date** (Token-2022 « scaled UI amount » côté Solana, rebase EVM) ; **surplus `balanceOf(pool)` vs réserves comptabilisées** — le mécanisme même qu'Uniswap décrit (« positive rebases create surplus balances not reflected in reserve accounting », R3 §2.3 [abs-WS→lu à T-2]). Consommateur : émetteur/TSV (Notice item i). Prérequis : lecture directe Uniswap « Token Integration Issues » + Token-2022 doc (procurement).
- **T-3 — classe `tsv-offhours-gap-<horizon>`** (M016) : variable `g_t` (D2 i) ; le curateur porte `yhat` (0 = « je tiens le dernier close ») ; scores `|g − ŷ|` ; verdict par le bras `interval`. **Mondrian imposé par la donnée : `(symbole × plateforme × régime)`** — le **régime** {overnight-semaine, week-end, férié} est un **axe Mondrian**, jamais un suffixe (sinon « copies d'horizon » interdites M016). Calibration = **rejeu de la Table 4 de Cong** sur fills xStocks/Ondo publics + close Polygon, **digest committé** (calque `STABLE_RUN_COMMITTED_CORE`). **Chiffres, α = 0,01** (⇒ `nMin = 1/α − 1 = 99` par cellule, borne finie non dégénérée ; **plus serré que Narabi α = 0,10** car le consommateur est un curateur de liquidation) : xStocks ≈ **300 sessions overnight** et ≈ **63 week-ends** par symbole à ce jour → week-end **`under_calib`** jusqu'à +36 week-ends ≈ **mi-2027 (≈ 2027-05/06)** ; fériés n ≈ 12 (toujours `under_calib`). **Ces comptes reposent sur une date de lancement rapportée [abs-WS] (2025-06-30) ⇒ le compte réel = premier fill mesuré en T-1a.** Population **TSV** (pool permissionné US plafonné) ≠ population xStocks ⇒ au lancement TSV, cellule TSV `under_calib` par construction. **Abstentions mécaniques** : halt en cours, volume nul, dislocation cross-plateforme xStock/Ondo > seuil, dépôt EDGAR horodaté dans la fenêtre (à vérifier), rebase non appliqué (`ex_date_effect`). **Phrase Barber 2023 Thm 2** (poids unitaires) : « n sessions, k/n dépassements au rejeu ; 1−α n'est la couverture que si l'écart de TV token est nul, non supposé ; aucune couverture n'est mesurée ». **α = 0,01 ratifiable au G0 de T-3, jamais implicite.**

### D5 — Oracles d'exécution / mutants (par lot, gain de correction dominant = oracle non-LLM)
Rejeu **bit-identique** du digest (T-1a). Mutants nommés, **rouge attendu** : **halt décalé d'une seconde** ⇒ `delta ≠` ; **close de référence changé** ⇒ `écart ≠` ; **fuseau faux (DST)** ⇒ rouge (deux halts réels épinglés du CSV, un EST un EDT — l'univers 24/7 étant vide de halts, la jambe on-chain du delta utilise une **fixture de fills épinglée**, la jambe CSV teste l'arithmétique ET→UTC sur halts réels) ; **casse de `Reason` non normalisée** ⇒ compte faux ⇒ rouge ; **signature retirée / « signed » = « verified »** ⇒ rouge ; `attested` discordant sur la classe T-3 ⇒ **400** (ADR-M017 D4). `gate:vocab` étendu à `apps/bell` (mots interdits D1 ⇒ insertion rouge).

### D8 — VPS dédié et Définition de fini (grade institutionnel, décision investisseur 2026-09-19)
**VPS dédié Bell dès T-1**, hôte **séparé** du VPS site/Narabi/harnais — motif : **indépendance du témoin** devant un examinateur SEC ou un curateur (joignable sans traverser l'app MONARK). Spécification minimale : **2 vCPU / 4 Go RAM / ≥ 40 Go disque** (collecteur périodique + serveur de fichiers statiques), **ordre de grandeur ≈ 5-15 $/mois** (classe Hetzner/OVH/DO, **fournisseur au choix de l'investisseur**, à confirmer sur grille) ; **NTP propre** ; **Caddy propre** servant **`bell.monarkgate.tech`** — **choisi** contre le reverse-proxy `/bell/` via le VPS site, qui **annulerait l'indépendance** (le record DNS = action sortante sous go). **Clé de signature Ed25519 propre** : chaque ligne de timeline est **signée** en plus du hash-chaînage (M012). **Honnêteté load-bearing** : la signature atteste **l'origine** (« ce VPS a publié cette ligne »), **jamais la vérité des faits** — le seul garant des faits reste le **recompute on-chain** (motif Narabi, M012 D4) ; « signed » ≠ « verified » (mutant D5).

**Définition de fini** (critères **vérifiables non-LLM** ; `built` conditionné à leur atteinte, D4) :
| Critère | Test non-LLM |
|---|---|
| Rejeu bit-identique de **chaque ligne publiée** depuis les entrées publiques | `bell_session_gap_identical_to_replay` sur la timeline live |
| Timelines **chaînées + signées Ed25519** | vérif de chaîne (`prev_line_hash`) + vérif de signature hors-ligne |
| Disponibilité mesurée | uptime publié ; **latence de publication ≤ 10 min** (aligné cond. G) sur flux TSV dès existence ; à T-1, cadence sentinelle |

| Abstentions **comptées et publiées** | compteur dans `state.json` ; non-régression |
| Journal de provenance + **page de méthode publique** | `docs/PROVENANCE-bell.md` + page `/bell/method` |
| **Zéro** « verified/guarantee/score » ; **export public gaté** | `gate:vocab` sur `apps/bell` + garde d'export |

- **Rebâtir un prix 24/5 / refaire le PoR / faire de la curation de risque (LTV)** : hors doctrine (mesurer ≠ pricer ≠ noter) ; Pyth/Chainlink occupent le prix, les curateurs le LTV — rejeté (mise en garde §6).
- **Market making conforme (produit 5)** : ferait de MONARK un dealer/« Covered Firm » (changement d'identité) — **écarté** (décision investisseur 2).
- **`attest` comme sujet de Bell à T-1** : harnais pur (K-8), `attest` input-less (ADR-M017 D2 (iv)) ⇒ impossible sans lot-harness ; **reporté à T-3** (voie honnête : fichiers publiés lus par le panneau à T-1).
- **Reverse-proxy `/bell/` via le VPS site** : annule l'indépendance voulue devant un examinateur ⇒ **VPS dédié + sous-domaine** (D8).
- **Ancrage on-chain des timelines** : clé chaude + gaz pour un gain marginal (M012) ⇒ **signature Ed25519 hors-chaîne** (origine, pas certification).
- **Booléen « conforme au halt »** : « concurrently » sans tolérance, seuil côté lecteur — rejeté (fait, pas verdict).
- **Régime en suffixe d'horizon** (`…-weekend`) : « copies d'horizon ≠ Mondrian » (M016) — rejeté ; le régime est un axe Mondrian.
- **Vendre un score / « ±X % à 90 % » / bande de prix** : doctrine violée — rejeté.
