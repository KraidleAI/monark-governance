## 2. Réponses aux six questions posées

**(a) Sur-déclaration réelle ? Remède = cp-1 U-4b-2 ou ruling ?** — **Réelle, mesurée.** Registre vide et description servie (tools/list via `registry.ts:137` → `registerTool` ; openapi via `openapi.ts:73`) portant « calibrated on one recorded episode » (`gate.ts:150`). La lecture « conditionnelle » que le carto laissait ouverte (« for the calibrated class » dans `LIQ_UPPER_BOUND_SENTENCE`) ne sauve pas `LIQ_H3_SENTENCE`, qui est **déclarative** : rien n'est calibré dans le registre servi. Le remède du plan (vide ⇒ phrase registre-vide ; non vide ⇒ phrases actuelles) est **exactement** celui déjà fixé au cp-1 U-4b-2 C-1 (`CHECKPOINT1-lot-u4b-2.md:98` : « la description ne contient aucune phrase de couverture ») et par le G0 lui-même (`G0-lot-u4b-2.md:55` : la phrase « upper bound » réservée à « registre non vide (-2b) » ; la description -2a = phrase requirements + phrase registre-vide). **Pas de ruling orchestrateur nouveau, pas de décision de valeur (CA-2 conforme).** La déviation -2a est une erreur de génération (G1 -2a contre son propre G0) doublée d'une erreur de vérification (G2 -2a et le checkpoint-2 -2a ont grep-contrôlé « 0 interval / 0 probabilité » sur la tranche, `CHECKPOINT2-lot-u4b-2a.md:27`, critère différent du C-1 « état du registre ») — voir CA-8 ci-dessous.

**(b) Ordre CARTO-T1C-2 → redéploiement ; la page `/ukemi` devient-elle VRAIE ?** — L'ordre est le bon (le redéployer avant publierait la description R-10, `CARTOGRAPHIE:246`). **(c) Re-pin h5 vs U-5b : doublon ?** — **Non, c'est la règle** : ADR-M017 C'-3 (`ADR-M017:82-83`) — tout lot qui change les octets de `tools/list` porte son propre re-pin, sinon `probe_harness_records_real_decision` rougit par construction. **(d) Anti-régression à -2b** — La bascule est automatique par construction (fonction du registre au chargement), mais **rien ne prouvera à -2b que la description bascule** tant que le registre est vide : `COMMITTED_CALIBRATIONS` est une constante de module, un seul état est observable par processus.
