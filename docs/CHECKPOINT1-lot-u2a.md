**Q-d — L'ordre linéaire ≥ exponentielle (C-8) est-il correctement énoncé ?**
- **Vrai** : pour tout x réel `1 − x ≤ e^{−x}` ⇒ `P_lin(Q) = c(1−ΛQ) ≤ c·e^{−ΛQ} = P_exp(Q)` pour tout Q ≥ 0 ⇒ `S_lin(Q) ⊇ S_exp(Q)` ⇒ `T_lin ≥ T_exp` **ponctuellement**. Le passage aux points fixes extrêmes exige le lemme manquant : si `T₁ ≥ T₂` ponctuellement et toutes deux monotones, alors par induction de Picard depuis 0 (`Q₁^{(k)} ≥ Q₂^{(k)}`) `Q_*₁ ≥ Q_*₂`, et depuis ΣB `Q^*₁ ≥ Q^*₂` — une ligne dans l'ADR-U2 et dans le commentaire du test.
- **Domaine** : `Λ·ΣB < 1` est le domaine du treillis linéaire (positivité, NOTE §3 Fait 1) ; l'inégalité `1−x ≤ e^{−x}` ne le requiert pas ; l'exponentielle est positive partout. Restreindre le test au domaine commun est correct ; à dire.
- **Appariement α = Λ : unités non déclarées.** La fiche BoE WP 264 [lu] écrit `p = e^{−α·s}` avec **s = ventes agrégées** (unités d'actif) ; la NOTE et le plan prennent **Q = dette liquidée** (monnaie de base). Écrire `e^{−Λ·Q}` sans dire que l'argument est Q dans les deux formes attribue au WP une forme qu'il n'a pas. L'ADR doit déclarer : « argument Q dans les deux formes (choix MONARK) ; α = Λ = appariement au premier ordre en Q = 0 (`dP/dQ|₀ = −cΛ` pour les deux) ». ⇒ C-5.
