## 3. Règles d'usage (à porter dans l'ADR de lot T-1a-ii)
1. **Quorum** : Helius est un fournisseur parmi ≥ 2 distincts (`providerOf`) ; une lecture Helius seule ⇒ `no_quorum` — même discipline que `rpc2.ts` (Ethereum).
2. **Crédits** : budget mesuré par produit dans Usage ; autoscaling **off** ; un lot qui consommerait > 1 M crédits/mois le déclare dans son ADR (coût récurrent).
3. **Clé** : `HELIUS_API_KEY` en env seulement ; jamais dans un fichier, un log, un artefact D9, un webhook URL committé ; `no_secret_in_repo` couvre le motif UUID Helius (à ajouter au test : 36 caractères `8-4-4-4-12` hex — item formé, lot T-1a-ii).
4. **Prix** : `price_info` DAS et tout prix Helius = **comparaison** (comme Pyth, ADR-B0 D6), jamais référence ni publication.
5. **Finalité** : toute lecture Bell = `commitment: finalized`, ancrée slot ; pas de preconfirmations/shreds.
