## 1. Ce que le rapport établit (chiffres tels que publiés, [2nd])
- Exploit **18 avril 2026, 17:35 UTC** : 116,5 k rsETH non adossés mintés via le bridge KelpDAO (LayerZero DVN 1-of-1, RPC empoisonnés + DDoS) ; ~**193 M$** empruntés sur Aave V3 en E-Mode (WETH contre rsETH à **93 % LTV**).
- Microstructure : de 17:35 à 19:56 UTC, dépôts WETH −294 k WETH ⇒ **100 % d'utilisation** ; pire semaine de sorties de l'histoire d'Aave **−8,67 Md$** ; au 20 avril USDC/DAI/USDT/USDe/WETH tous à 100 %.
- **Levier caché du loop** : 98,5 % du collatéral des emprunts WETH = LST ETH (**5,43 Md$ / 5,52 Md$**) ; top 10 emprunteurs WETH = 3,65 Md$ (65,4 %) tous en loop LST (weETH, rsETH, wstETH). Cascade de pertes : looper (equity) → **Umbrella WETH** (junior) → déposants aWETH → DAO. Les déposants WETH sont « de facto third-loss » ; un seul taux de pool pour des profils de risque différents.
- Réponse Aave : gel rsETH/wrsETH **85 min** après l'exploit ; taux d'emprunt WETH à **10,5 %** ⇒ Slope2 abaissé pour ramener le taux à 100 % d'utilisation à **3 %** ; marché WETH gelé ; aWETH a coté jusqu'à **−8 %** du pair ; liquidateurs payés en aWETH illiquide (incitation dégradée) ; report du risque vers les marchés stables (utilisation → 100 %, taux ~15 %).
- **Umbrella** : > 370 M$ levés depuis juin 2025, cible **250 M$** avant l'exploit ; bad debt historique **< 5 M$** ; couverture 1,5-2 % de la base USDT/USDC/WETH ; coût 8 M$/an de revenus protocole ; **Umbrella WETH = 23 507 aWETH (~54 M$)**, dont **80 % déjà en cooldown 20 j** ; LlamaRisk a proposé de geler le module.
- **Deux scénarios (service providers Aave)** : S1 socialisation uniforme Kelp (haircut 15,12 % sur tous les rsETH) ⇒ ~**124 M$** de bad debt, dont **91,8 M$** sur Ethereum Core WETH ⇒ Umbrella (54 M$) couvre ~59 %, reste ~38 M$ (haircut aWETH Core ~0,60 %) ; S2 pertes isolées sur L2 (haircut 73,54 %) ⇒ ~**230 M$** entièrement sur L2, Mantle −71 % WETH, **Umbrella ne se déclenche pas** (couvre mainnet seul). Trésorerie Aave **150 M$**.
- Parts de marché : dépôts Aave −30 % en 4 jours ; part 68 % → < 61 % ; prêts 65,5 % ; **SparkLend** +1,8 Md$ d'entrées (19-21 avr.), +540 M$ de net borrow, > 350 M$ de liquidité spUSDT — sans exposition rsETH (déprécié en janvier), caps rate-limités.
- Thèse : pools monolithiques = socialisation et sous-tarification du risque de collatéral « discret » (bridge/smart-contract) ; modulaire (Morpho, Kamino V2, Euler V2) isole mais ne supprime pas la contagion corrélée (≈ 15 vaults Morpho touchés par l'exploit Resolv USR) ; CeDeFi (Maple, Pareto, Wildcat) = liquidations non atomiques, recours légal ; segmentation attendue par classe de risque. Aave v4 : Risk Premiums par collatéral, hub-and-spoke.

## 2. Ce que cela apporte à MONARK
- **Ukemi / ADR-M020 (thèse « eligible ≠ liquidated », canaux qui cassent le chemin continu)** : l'événement rsETH est un **gap discret exogène** (collatéral non adossé révélé d'un coup, pas un chemin de prix) — exactement le canal « discrete price gap » de Gatto (Table 9) et non le canal oracle ; les liquidations y ont été **dégradées par l'illiquidité du pool** (liquidateurs payés en aWETH) = canal « pool fini » de Gatto. Deux épisodes réels de plus pour U-5 (rejeu) : à recouper sur les threads primaires 24481/24580 (archivés) — le rapport Messari ne remplace pas la source.
- **Payeur (avis advisor-marché)** : la question « qui absorbe » est posée explicitement (looper → Umbrella → déposants → DAO) ; Umbrella = précédent d'un **capital junior stakable** dont la couverture est calibrée sur l'historique (< 5 M$) — argument pour une mesure de classe (b)/(c) consommée par les stakers Umbrella et le DAO (à instruire dans le GTM Ukemi, pas ici).
- **Vocabulaire** : le rapport parle de « bank run », « bad debt », « contagion » — motifs bannis sur les surfaces MONARK (`vocab-banned.json` scope sentinel : `cascade`) ; ne jamais recopier ces formulations dans du code ou des docs exportés.
