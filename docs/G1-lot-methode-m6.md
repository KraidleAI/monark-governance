## 3. Interface (tâche 2)
`node scripts/mutants/run.mjs --repo <worktree> --base <sha> --out <dir> [--table <mutants.mjs|.json>] [--killers] [--only <id,…>] [--targets <test.ts,…>] [--timeout-ms n] [--min-free-mb n] [--lock-root <dir>]`
- **Mutants** : `--table` (module exportant `MUTANTS` ou JSON, lignes `{ id, line, op, before, after, why[, file][, test] }`, `op` ∈ COR, ROR, SDL, CONST ; SDL vide la ligne comme `red-proof.mjs`) ; une ligne sans `file` mute LE fichier de code non-test que `base..arbre` change (sinon exit 2) ; `--killers` : lignes `// killer:` des fichiers de test de `base..arbre` lues par `parseKiller`, `id` = `K<n>` (fichiers triés, puis ligne), `why` = « killer of <titre> », premier passage = ce test seul (`--test-name-pattern=^titre$`) dans son fichier.
- **Cibles** : `targetsOf(repoRoot, file, testGlobs)` (pure, exportée) rend `{ direct, transitive }` : fichiers des globs cités du script `test` de `package.json` dont la fermeture des imports statiques (`import … from`, `export … from`, `import "…"` ; relatifs et `file:` ; `.ts` `.mts` `.mjs` `.js`) contient le fichier muté ; premier passage sur les importeurs directs (un tueur : son propre fichier), survivant rejoué sur TOUTES les cibles entières ; aucune : `--targets`, sinon exit 2 « no target ».

- **Mutant inapplicable** (`lostOf`, avant tout clone, puis de nouveau sur les octets du clone) : opérateur hors COR/ROR/SDL/CONST ou `<before>` vide (possible pour un tueur ; pour une ligne de table c est un exit 2), fichier absent ou hors de l arbre, fichier de test (`test/`, `*.test.ts`), `<before>` pas exactement une fois sur sa ligne ⇒ `anchor-lost` avec sa raison dans `note`, compté, jamais appliqué, sans cible exigée.

Exit 0 ssi tous tués ; 1 sinon ; 2 refus ; 3 restauration.
