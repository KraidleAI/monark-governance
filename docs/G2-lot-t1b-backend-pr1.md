## Observations (non bloquantes pour ce G2 ; chacune portée par un ruling demandé ou un item formé, aucun « dû » nu)

- **O-1 — republication inter-publications (demande de ruling formée).** Sonde P-1 (`probes-golden.tap`) : un run publié à seq 1 est republié à seq 3 s'il est redéposé après une autre publication (C-in-9 compare à la DERNIÈRE ligne ; C-in-10 est intra-bundle, `bell-publish.mjs:262-276`). L'ADR v2 §D4 motive C-in-10 par « jamais un run publié deux fois » ; la lettre des contrôles ne le garantit pas entre publications. Options : (a) garder et l'écrire dans l'ADR (l'état courant est toujours le dernier bundle ; la timeline peut citer un même `bell_sha` deux fois) ; (b) étendre `duplicate_run` à tout `bell_sha` déjà présent dans une ligne commitée (≈ 1 ligne de code + un test) ; (c) accepter mais marquer la republication. Avis (pas un verdict) : (b), cohérent avec la phrase de l'ADR et fail-closed. Item **BELL-REPUBLISH-RULING-1**, propriétaire orchestrateur, déclencheur : avant le G7 PR-1. `error_origin` : rédacteur G0.
- **O-2 — gap `gT` sans `earliest_publish_utc` (demande de ruling formée).** Sonde P-2 : un tel gap (forme d'un collecteur antérieur à -b3b, le type rend le champ optionnel, `digest.ts:87`) passe C-in-5 et publie à l'horloge 0 (`bell-publish.mjs:123-126` ne refuse que si le champ est présent). Les deux sites de construction actuels le posent toujours (`collect.ts:200,207`). Durcissement possible : refuser un gap porteur de `gT` sans le champ (≈ 1 ligne + un cas de test, peut se plier avec C-1). Item **BELL-EPU-ABSENT-1**, orchestrateur, déclencheur : ruling avant le G7 PR-1, au plus tard G-e. `error_origin` : rédacteur G0 (C-in-5 formulé sur la valeur, pas sur la présence).
- **O-3 — démarrage sans re-`fsync` de la timeline privée.** Si le processus meurt après le `writeSync` de la ligne mais avant son `fsync` (`bell-publish.mjs:291`), le redémarrage la tient pour commitée et re-dérive `public/` (fichiers fsyncés) sans re-`fsync` du privé ; une coupure de courant avant le vidage du cache peut alors laisser `public/` en avance ⇒ refus `existing_timeline_corrupt` (fail-closed, réparation manuelle), jamais un service silencieux.
