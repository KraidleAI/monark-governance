## Hypothèses testables
1. **La méthode PoC (mint gTfA `full` tally → vault le plus tally) trouve le(s) pool(s) fondateur(s) 2025** — falsifiable sur la re-mesure live (TSLAx `CY9Xzc1z…` reproductible ; part couverte ≥ seuil ; ≥ 1 vault par mint sinon `founding_pool: null` déclaré).
2. **Le quote vault s'identifie par delta signé opposé apparié au base vault dans la même tx** (sans décoder le layout AMM) — falsifiable sur une tx réelle (delta base + delta quote de signes opposés, dédup par signature).
3. **`replayTriplet(events, S)` == `ScaledUiAmountConfig` lu base64 quorum-2 au slot S, sur les bits** (ancrage C-3) — falsifiable ; une divergence ⇒ `rebase_unverified`, jamais un ajustement.
4. **Aucun `UpdateMultiplier` ne se pose entre le scan de trajectoire et la course** (sinon l'ancrage C-3 fait abstenir) — falsifiable par re-lecture de l'état à la course ; conséquence fail-closed déclarée.
5. **Chaque `founding_pool` porte assez de fills in-window pour un g_t par régime** (TSLAx 5000+ plancher) — falsifiable à la sonde -ii (compte exact) ; pool quasi-dormant ⇒ n par régime publié, jamais une course partielle présentée complète.
6. **Chaque `founding_pool` retenu est quote-USDC** (VWAP directement en USD contre le close) — falsifiable à la découverte (L-1, `quoteMint` lu on-chain) ; un quote non-USD ⇒ `quote_class:"non-usd"`, **exclu de -ii** (jamais une g_t via un taux tiers, ADR-B0 D6).
